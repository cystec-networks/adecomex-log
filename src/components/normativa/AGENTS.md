# Base normativa rules
- Base normativa PDFs live in the private `base-normativa` bucket (admin-only); processing is two admin server fns — `extraerDocumentoNormativa` (unpdf per-page text, scanned detection, `fragmentarDocumento` page/article chunks stored without vectors) then `vectorizarDocumentoNormativa` called repeatedly by the page for bounded embedding batches — so long documents never exceed one request and an interrupted run resumes from the remaining NULL embeddings. Extraction suggests number/issue date via the pure `detectarDatosDocumento` only into empty or still-unconfirmed fields (`*_detectado` flags), so a value confirmed or typed by an admin is never overwritten. Embeddings use `embeddings.server` (one model/dimension for documents and queries; changing it requires re-embedding every document).
- Base normativa PDFs open in `components/normativa` (pdf.js PDFViewer + find controller) through our own Range transport with small chunks (`normativa-visor`), because storage hides Accept-Ranges from CORS and large chunks download whole PDFs whose page objects are scattered; pdf.js wasm/fonts are self-hosted under `public/pdfjs`. Assistant citations are internal `/normativa/<id>?pagina=N` links built from fragment data and opened in the same viewer; staff may read the bucket since they already read the extracted text.
