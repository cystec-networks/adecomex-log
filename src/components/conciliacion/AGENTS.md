# Bank reconciliation rules
- Exact-suggestion TF assignment runs only through `private.tf_para_entradas` (preview and confirm share it); hand-typed prior-register TFs are validated there, reserved before automatic numbers, never move the sequence and set `tf_excel` instead of `tf_retroactivo`, so preview and commit cannot diverge.
- Post-import auto-reconciliation: `planConciliacionAutomatica` (pure, tested) classifies only the newly inserted debits; `conciliar_automatico_importacion` revalidates every item server-side in its own savepoint (failures fall back to review with a reason) and records a `banco_lotes_automaticos` batch, so one stale item never blocks the rest and the whole batch is undoable via `deshacer_lote_automatico` (created entries are voided, never deleted).
